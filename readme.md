# IELTS Quest: Reading Realm

A free, static IELTS Reading practice game made with HTML, CSS, and JavaScript. No API key, build tools, or paid services are required.

## Included
- Responsive phone and desktop layout
- Six original reading passages with answer keys and explanations
- Multiple choice, True/False/Not Given, Yes/No/Not Given, short answer, sentence completion, and matching-information style questions
- Instant feedback and evidence from the passage
- XP, levels, progress, streaks, achievements, and mistake notebook
- Timed mixed-practice mode and quick daily challenge
- Local browser storage; progress does not sync between devices
- Netlify-ready static files

## Run it
Unzip the project and open `index.html` in a modern browser. You can also open the folder in Visual Studio Code and use the Live Server extension.

## Publish to Netlify
1. Sign in at https://app.netlify.com/
2. Choose the option to add a new site or deploy manually (labels may change).
3. Drag the unzipped project files (`index.html`, `styles.css`, and `app.js`) into the manual deploy area.
4. Netlify will show you the public website URL after deployment.

Alternatively, upload these files to a GitHub repository and connect that repository to Netlify. Leave the build command blank and use `.` as the publish directory.

## Important
This is an independent practice project, not an official IELTS product. The demo bank is not a full official 40-question IELTS test and does not estimate an official band score. Expand and proofread the question bank before relying on it for exam preparation. Local storage can be lost if browser data is cleared. No dynamic AI generation is included, keeping the starter version free.
